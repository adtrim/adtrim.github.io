  1. Fixes and security updates

    Fixes and security updates

    Nothing changes in how you use AdTrim. The release notes on GitHub list each fix.

  2. 2.1.0

    MP4 or TS, from recording to export

    Open MP4 and single-program TS recordings, edit them the same way, and export either format. Windows Explorer's Edit with AdTrim action now supports TS too.

    Find recordings that still need exporting

    File > View Unexported Files lets you browse a folder and open recordings that still need work. Successful exports are recorded in the existing project sidecar. MP4 recordings can also receive an export marker in Windows Comments; control that with File > Add Comment to Source File on Export.

    TS recordings are not modified. Deleting their project sidecar removes their export status.

    More accurate previews and exports

    • Fixed TS seeking and the preceding-frame preview when clicking the timeline.
    • Fixed missing opening audio, delayed video at TS cuts, and accumulated timing errors across joins.
    • Improved MP4 chapter timing and TS audio timestamps at joins.
    • Existing source damage alone no longer blocks an otherwise possible export.
    • Export settings use separate cards in one column, with a prominent TS chapter notice and export actions that remain visible while settings scroll.

  3. 2.0.0 · Major release

    Thumbnails, a waveform, and ad break suggestions

    The timeline now shows what's in the recording, not just where your markers are. You can see the show, see where it goes quiet, and ask AdTrim to find the breaks.

    Silences you can see

    Commercial breaks often begin and end with a beat of silence. The waveform marks those moments in amber, measured against each recording's own quietest sound, so a quiet drama and a loud game show both get useful marks.

    Ad break suggestions

    Analyze ad breaks looks at the picture and the sound and adds markers where it finds likely breaks. It never excludes anything on its own. Markers it isn't sure about are red, so you know which ones to check first.

    It's new. It can miss a break or place a boundary a little early or late, so review each suggestion before you export.

    How fast it is

    0.6 sfrom opening a recording to working on it
    1.7 sfor the full thumbnail strip
    27 msfor a typical scrub while thumbnails and the waveform load

    Measured with a 2.0 test build on one 110-minute, 8 GB recording stored on a home network share. The opening time is from a first open; the thumbnail and scrub times are from after the share had read the file once. Your times depend on your drive and network.

    Also in 2.0

    • Select many markers at once: all, red, or visible, then confirm, refine or delete them together.
    • Move between markers with Alt+Left and Alt+Right. Shift+N goes to the previous unconfirmed split.
    • Rename a section with F2. Press F1 for every shortcut.
    • Start new recordings with imported markers, AdTrim's suggestions, or none, under Tools > Ad break detection.
    • Delete all markings (Ctrl+Del) replaces Clear all markings, and is now in the Edit menu too.
